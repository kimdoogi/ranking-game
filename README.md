## 실행 방법

별도 설치 없이 HTML 파일을 더블클릭하거나 브라우저에서 열면 됩니다.

## 자동 달리기와 괴물 추격전

두 게임 모두 이름을 넣고 출발하면 끝까지 자동으로 진행됩니다. 달리기는 매번 출발 자리와 능력치를 새로 뽑고, 세 아이템 게이트에서 로켓·방패·바나나·도약을 얻습니다. 자동 바나나 비와 전원 가속 구간, 실시간 선두 3명과 거리 차이, 결승 판독과 최종 시간 차이를 보여줍니다. 첫 완주 뒤에는 나머지 참가자를 3배속으로 중계합니다. 종료 제한까지 완주하지 못한 참가자는 진행 거리 순으로 DNF 처리합니다.

괴물 게임은 자동 야식 배달로 추격 대상을 바꾸고, 현재 타깃과 최근 탈락자를 표시합니다. 두 게임 모두 고정된 물리 공간과 60Hz 시뮬레이션을 사용하며, 화면 회전은 카메라만 바꿉니다. 모바일에서는 높은 시점, 화면 크기에 맞는 이름표와 스크롤 가능한 대기실을 사용합니다.

`node check-races.cjs`로 아이템, 자동 이벤트, 완주 판정, 재시작 초기화와 최대 인원 경기를 확인합니다. 같은 난수 조건에서 화면 크기·회전·효과 품질을 바꿔도 순위가 같은지 검사합니다. 화면 연출은 `obstacle-run-fx.js`, 경기 로직은 `obstacle-run.js`에 있습니다.

## 밀어내기 배틀 로얄 검증

이름을 넣고 시작하면 끝까지 자동으로 진행됩니다. 흔들기 등 결과에 개입하는 조작은 없으며, 자동 폭발과 중앙 충격파가 예고 후 발생합니다. 모바일에서는 높은 시점과 자동 확대를 적용하고, 화면 회전은 전투 물리에 영향을 주지 않습니다.

`node check-push-royale.cjs`로 게이지, 필살기 4종, 자동 무대 이벤트, 개입 조작 부재, 재시작과 경기 완료를 확인합니다. 같은 난수 조건에서 모바일·데스크톱·경기 중 화면 회전의 최종 순위가 일치하는지도 검사합니다.
화면 문구·구조는 `build-pages.py`에서 수정한 뒤 `python3 build-pages.py`로 생성하고, `python3 check-i18n.py`로 4개 언어를 확인합니다. JS·CSS 수정 후에도 생성기를 실행해 캐시 버전을 갱신합니다.

## 인형뽑기 대탈출 검증

이름을 넣고 시작하면 집게가 끝까지 자동으로 인형을 뽑아 탈출시키고, 마지막까지 안 뽑힌 인형이 커피 당번(꼴찌)이 됩니다. 인형은 물리 엔진 대신 고정된 육각 슬롯 격자에 쌓이고, 집게가 잡는 순간 성공·미끄러짐·걸침 결과를 미리 굴려 정해진 상태 전환과 이동으로 풀어냅니다. 경기는 고정 60Hz 시뮬레이션으로 진행되며, TILT·꽝 오리·잭팟 같은 자동 이벤트는 예고 후 발생합니다. 흔들기나 탭처럼 결과에 개입하는 조작은 없습니다.

난수 시드는 경기마다 `Math.random`을 한 번만 호출해 뽑고, 이후 모든 판정은 그 시드의 난수만 씁니다. 연출·효과음·말풍선은 별도 난수를 쓰고 카메라만 화면에 맞추므로, 화면 크기·회전·동작 줄이기 설정이나 프레임 속도가 달라져도 꼴찌는 바뀌지 않습니다. 집게의 목표는 이름이나 입력 순서가 아니라 슬롯 위치로만 정해져 모든 참가자의 꼴찌 확률이 1/N입니다.

`node check-claw-escape.cjs`로 2·12·30명 전체 경기, 모바일·데스크톱·경기 중 회전·동작 줄이기·30fps에서 순위가 일치하는지, 개입 조작 부재, 재시작 초기화, 예고 이벤트, 결승 시도 상한과 카이제곱(chi²) 공정성 검사를 확인합니다. 화면 연출은 `claw-escape-fx.js`, 경기 로직은 `claw-escape.js`에 있습니다.
